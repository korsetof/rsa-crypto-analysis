## RSA

Основные параметры:

n = p × q

φ(n) = (p − 1)(q − 1)

Открытый ключ: (e, n)

Закрытый ключ: (d, n)

Шифрование: C = M^e mod n

Расшифрование: M = C^d mod n

## Методы криптоанализа

### 1. Полный перебор (Brute Force)

При известных e и n программа перебирает возможные значения закрытой экспоненты d и проверяет результат.

### 2. Факторизация

Если удаётся представить n = p × q, становится возможным вычислить функцию Эйлера φ(n) = (p − 1)(q − 1), после чего восстановить d из условия e × d ≡ 1 (mod φ(n)).

### 3. Анализ сообщения

Программа демонстрирует учебные сценарии восстановления исходного сообщения при известных параметрах RSA.
